# Country flag sources

Downloaded on 2026-11-04 from [hampusborgos/country-flags](https://github.com/hampusborgos/country-flags), `main/svg/{at,ro,gr,cl,sg,it}.svg`. The six SVG files are unmodified source assets.

The [source README](https://github.com/hampusborgos/country-flags/blob/main/README.md) states: “The source files were taken from Wikimedia Commons and sometimes contributed back” and “The flags are not under copyright protection since flags are in public domain”.

Countries: Austria, Romania, Greece, Chile, Singapore and Italy. Original flag proportions are preserved through intrinsic SVG geometry and `object-fit: contain`. No source repository code or third-party dependencies are included.
